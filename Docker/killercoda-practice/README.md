# 🐳 Docker Hands-on Assignment – KillerCoda

## 📌 About

This folder contains my Docker hands-on assignment completed using the KillerCoda interactive learning platform.

The assignment helped me understand important Docker concepts through practical exercises and command execution.

## 📚 Topics Practised

### 1. ADD and COPY
- Copying files and directories into Docker images.
- Understanding the differences between ADD and COPY.
- Using these instructions in Dockerfiles.

### 2. Docker Image Building
- Creating custom Docker images.
- Building images using Dockerfiles.
- Understanding the Docker build process.
- Running containers from custom images.

### 3. CMD and ENTRYPOINT
- Understanding container startup behaviour.
- Using CMD to define default commands.
- Using ENTRYPOINT to configure the main executable.
- Understanding the differences between CMD and ENTRYPOINT.

### 4. Docker Compose
- Defining services using compose.yaml.
- Running multiple containers together.
- Managing services using Docker Compose commands.

### 5. Docker Network Drivers
- Bridge network.
- Host network.
- None network.
- Understanding container communication.

### 6. Bind Mounts
- Mapping host directories into containers.
- Sharing files between host and containers.
- Understanding file synchronization.

### 7. Docker Volumes
- Creating and managing Docker volumes.
- Understanding persistent storage.
- Persisting data independently of container lifecycle.

### 8. Environment Variables
- Passing environment variables to containers.
- Configuring containers dynamically.
- Using environment variables in Docker Compose.
- Avoiding hardcoded configuration values.
